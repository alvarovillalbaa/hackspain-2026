# Post-run Check

Before returning a roast:

1. Confirm explicit roast consent in the current request.
2. Confirm every punchline targets behavior, a decision, a process, a work product, or an outcome.
3. Confirm every receipt has provenance and that interpretations are labeled as inferences.
4. Remove protected-trait, sensitive-trait, diagnosis, intelligence, morality, and intent claims.
5. Remove any private fact that was not provided or explicitly authorized for this task.
6. End with one to three measurable actions.
7. Leave memory unchanged unless a separate write was explicitly approved.
